i need to add robot.txt, sitmap.xml and llms.txt file in my nextjs site i have got the content tell me hwo to addd?

Since your site is using the App Router (app/ directory), you have two straightforward approaches: Method 1 (Static files in public/) which is the quickest since you already have the file contents prepared, or Method 2 (Next.js App Router metadata conventions).

Method 1: Drop Them Directly into public/ (Recommended & Simplest)
Any file placed inside the public/ directory at the project root is served directly from the root URL (/robots.txt, /sitemap.xml, /llms.txt).

If you don't already have a public folder at the root level of mintrix-trading, create one:   
PNG

Plaintext
mintrix-trading/
├── app/
├── components/
├── data/
├── public/
│   ├── robots.txt
│   ├── sitemap.xml
│   └── llms.txt
├── package.json
└── next.config.mjs (or .js)
Inside public/, create:

robots.txt (paste your robots rules)

sitemap.xml (paste your XML sitemap)

llms.txt (paste your Markdown/plain text content for LLM scrapers)

Note: Ensure the file is named robots.txt (with an s), not robot.txt.

Once created, you can test them locally:

http://localhost:3000/robots.txt

http://localhost:3000/sitemap.xml

http://localhost:3000/llms.txt

Method 2: App Router Native Route Files (Alternative)
Next.js App Router has native support for static metadata files placed directly under the root app/ folder:

app/robots.txt: Place your static content directly in app/robots.txt. Next.js will automatically serve it at /robots.txt.

app/sitemap.xml: Place your static XML directly in app/sitemap.xml. Next.js serves it at /sitemap.xml.

llms.txt: Because llms.txt is not a default Next.js metadata convention, the cleanest approach is to put it in public/llms.txt (or create a Route Handler at app/llms.txt/route.ts if dynamic serving is needed).
